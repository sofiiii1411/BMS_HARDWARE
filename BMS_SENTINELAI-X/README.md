# BMS SentinelAI-X Module

This directory contains the hardware sub-systems, firmware code, and documentation for BMS SentinelAI-X.

- `DOCUMENTATION/`: Circuit schematics, pin maps, and hardware reports.
- `HARDWARE/ROOM101_ECOSPACE/`: Firmware and drivers for EcoSpace deployment.
- `HARDWARE/ROOM201_SECURELAB/`: Firmware and drivers for SecureLab deployment.
- `HARDWARE/SHARED_HARDWARE/`: Shared communication (WiFi/MQTT) and relay modules.
